Last Updated & Effective Date: October 2026 | Developer: Sensora Labs

Zero Data Collection Summary

The Shubh app does not require account creation, does not collect names, email addresses, phone numbers, contacts, device identifiers, or biometric data, and does not sell or share any user metrics with third parties.

2. Location Data Handling

To provide precise Vedic calculations (such as city-accurate Sunrise, Sunset, Rahu Kaal, and Choghadiya), the application may request coarse or fine location permission. All location coordinates are processed strictly on-device in real-time (ephemerally) and are never transmitted over the internet or saved to external databases. If location permission is denied by the user, the app seamlessly falls back to standard New Delhi reference coordinates with zero loss of core functionality.

3. Offline Storage & Asset Integrity

All astronomical ephemerides for the years 2026 and 2027 are packaged directly inside the application bundle in an encrypted, read-only SQLite database. User preferences (such as selected language: Hindi or English) are stored locally on your device via standard sandbox storage (SharedPreferences) and never uploaded to any remote server.

4. Advertising and Analytics

The core MVP version of the Shubh application contains zero third-party tracking SDKs, zero analytical profilers, and zero interstitial ad networks. We respect your peace of mind and cultural practice.

Step-by-Step Tutorial

GitHub Pages Par Ye File Live Kaise Karein

Google Play Console me Privacy Policy URL daalne ke liye 3 minute ka setup.

Step 1: GitHub Par New Repository Banayein

GitHub.com par jaayein -> New Repository par click karein.
Repository Name rakhein: shubh-privacy (ya apni marzi ka naam).
Isko Public select karein aur Create repository daba dein.

Step 2: Yeh index.html File Upload Karein

Repository khulkar Add file > Upload files par click karein.
Is poori file ko index.html naam se upload karke Commit changes kar dein.

Step 3: GitHub Pages Enable Karein

Repository ke Settings tab me jaayein.
Left sidebar me Pages par click karein.
Branch me main (ya master) select karein aur folder / (root) chunein, fir Save karein.

Step 4: Play Console Me URL Daalein

1 minute me aapka page live ho jayega:
https://<your-username>.github.io/shubh-privacy/ Google Play Console ke App Content > Privacy Policy me yahi link paste kar dein!
